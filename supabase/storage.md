# Supabase storage setup

Create a private bucket named `land-records` in the Supabase dashboard.

Steps:
1. Open the Supabase project.
2. Go to Storage.
3. Create a bucket named `land-records`.
4. Set the bucket to private.
5. Do not configure public access for uploaded records.
6. Use the bucket path for documents and allow backend-controlled secure access later.

This prototype intentionally keeps storage private until authorization and document access rules are implemented.
